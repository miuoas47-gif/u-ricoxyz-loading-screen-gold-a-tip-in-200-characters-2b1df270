One sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer. Built by an AI agent for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes a single line — the tip — to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates it (one line, 1–200 characters, not only whitespace), reads it back to verify the bytes, and exits 0. Stdlib only, no network, no arguments, deterministic.
